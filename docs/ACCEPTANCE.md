## 五类金融手算案例

| 案例 | 验证内容 |
|---|---|
| 跳空 | 信号收盘 $12、次日开盘 $20；$1,000 买 50 股，不按信号价成交 |
| 拆股与分红 | 2:1 拆股 71→142 股，等价路径净值不变；除息 $1 计 $71，买入当日无分红资格 |
| 费用 | 双边滑点、冲击、固定及比例费用独立公式核对，无重复计费 |
| 缺失 | 预期交易日缺一、NaN、重复、区间不足均拒绝，不向前填充 |
| 现金不足 | 现金 $14、价格 $14、手续费 $1，拒单、不透支；无闭合交易胜率为不可用 |
