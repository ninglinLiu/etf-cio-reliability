## 五类金融案例的预期值

| 案例 | 独立验收点 |
|---|---|
| 跳空 | 信号日收盘 $12，次日开盘 $20；$1,000 买 50 股，不能按 $12 成交 |
| 拆股/分红 | 2:1 拆股 71 股变 142 股，等价路径净值不变；除息 $1 时 71 股收 $71，价格同步降 $1 后净值不变；新买入者不领当日股息 |
| 费用 | $14/$8 买卖，71 股，双边计入滑点、冲击、固定及比例费用；现金等于独立公式 |
| 缺失 | 去掉一个预期交易日立即拒绝；NaN、重复日期、覆盖不足拒绝 |
| 现金不足 | 现金 $14、开盘 $14、手续费 $1，拒绝买入而非透支；无交易胜率为不可用 |
