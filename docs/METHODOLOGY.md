# 方法与复核口径

## 策略与账本

SPY、20/50 日简单移动平均、只做多或现金。严格上穿：昨日快线 ≤ 慢线且今日快线 > 慢线；下穿相反；相等不交易。信号收盘产生，次交易日开盘成交。初始现金 $100,000，不为样本开始前的交叉补仓；样本前一日收盘产生的订单可以在样本首日开盘执行。以整数股买入，预算包括全部成本，余额为现金，无融资。

数据源为 yfinance/Yahoo 日线，固定 `auto_adjust=False, back_adjust=False, actions=True, repair=False, keepna=True`。完整保存其返回表格字段，不把该表格称作原始 HTTP 响应。下载数据是当前可得版本，不是 point-in-time 历史供应商快照。下载参数的结束日为排他端点，见 [官方接口说明](https://ranaroussi.github.io/yfinance/reference/api/yfinance.download.html)。

成交和市值使用不作股息复权的 OHLC；Adj Close 仅留存供检查，计算不使用。Yahoo 的 OHLC 仍可能拆股调整，故真实数据适配器遇到样本内拆股会明确拒绝，等待实现 as-traded 转换；不能让拆股调整价格再乘一次拆股股数。通用账本以 as-traded 数据为前提，合成案例验证 2:1 拆股股数/价格的财富恒等及信号连续性；未支持拆股导致碎股的 cash-in-lieu。

分红归属除息日前已持有的股份；除息日开盘买入不领取该次分红。本版缺实际支付日，**明确假设除息日现金到账**；可能提前增加可投资现金，不能声称已完整模拟实际交收。没有复权收益加股息现金的双计，也无自动 DRIP。期末按收盘市值，不强制虚构一笔清仓。现金不计息，未计个人税、真实交易所费用及税收账户差异。

## 成本

- 滑点：每单 5 bp，买价加、卖价减。
- 交易费：每单 $1；比例费配置为 0 bp，支持非零配置。
- 市场冲击：订单按原开盘价计的名义金额 / 前 20 个完整交易日平均日成交额 >1%，额外 10 bp；只用执行日前数据。样板账户规模较小，真实样本冲击费用为零；合成测试强制触发此分支。
- 阈值分母原任务未明确，本版选用流动性参与率而不是“占组合净值的仓位比例”，并在报告中标明。该函数是显式假设，不声称是经实证校准的冲击模型；未模拟开盘集合竞价容量或部分成交。
- 成交价已含滑点和冲击，账本不会额外重复扣这两项费用。买入股数通过单调预算搜索保证现金非负。

## 指标与独立复核

收益率 = 末期净值 / 初始现金 − 1。年化 = `(末期净值/初始现金)^(252/样本交易日数)-1`。净值包括现金与证券收盘市值；首日收益相对初始本金。最大回撤包含初始本金为基准的峰值。夏普采用日超额收益均值 / 样本标准差 × √252，无风险年化配置默认为 0。

成交笔数计每次买/卖 fill；完整交易次数计闭合持仓周期。胜率按完整交易的净盈亏（含进入/退出费用与期间分红）大于零计；未平仓不进入胜率分母，零收益不算胜。无闭合交易、零波动分别标记不可用，而非伪造为 0。

`scripts/audit_result.py` 不导入主引擎，读取冻结行情、成交价格/股数/费用，重新计算每日分红、现金、持仓及净值。另有手算合成案例约束信号日、成交日、价格和净盈亏，防止仅有自我一致性检查。

## 比较与外部复现

本地简化参考使用同一交叉信号、同 SPY 和同区间，直接累乘下一段收盘到收盘收益，不计成本、允许分数份额、即时再投股息。它会把建仓前隔夜收益纳入，不能当作可成交账本。这是明确标识的新建参考，不是用户原项目的简化算法。

机构文章复现仍未通过。本次核对了 AQR 的 [A Century of Evidence on Trend-Following Investing](https://www.aqr.com/Insights/Research/Journal-Article/A-Century-of-Evidence-on-Trend-Following-Investing)（2017-10-31）：它研究多类期货/远期的时序动量，样本追溯到 1880；不是 SPY 20/50 日均线样板，不能拿本样板数字与其收益/回撤直接比较。这是待选参考的排除理由，不是完成了机构对标。

正式对标需冻结原文、表格、规则、品种、样本、费用、现金利息、收益类型、年化和回撤频率，分别计算收益/回撤/交易次数偏差。`abs(复现值-原文值)/abs(原文值) <= 10%` 为相对误差，而非差 10 个百分点。原文为零或不披露时应单列待定口径，不能自动算通过。不能调整样本或参数来凑验收数值。

## 可靠性边界

输入指纹绑定规则和所有配置、数据字节、来源、数据截止/下载时间、计算源码哈希及最后修改计算源码的 Git 提交、Python 和依赖版本。文档或证据提交不会改变计算提交；源码未提交修改仍被文件哈希识别。

`run_id` 同时作为本地幂等键；同键同冻结输入复用原结果或原失败，同键异输入拒绝；主动重算使用新键。目录创建为排他操作，进程中断留下的不完整目录会拒绝使用，需新键重跑。调用日志追加写入但未提供多进程日志行事务保障；不声称是生产级分布式 exactly-once。

完整性检查发现缺文件、内容变化、输入不匹配或失败状态即拒绝。没有 DAG、CIO 状态机、下游业务记录、真实审批或自动推进。**本地 gate 的存在不证明 CIO 会调用它**，必须在原项目入口接入并测试，才能验收任务二。

ETF 样板不证明选股可信。未解决历史成分股、退市样本或财报当时版本；不宣称消除幸存者偏差与前视偏差。本策略不调用 LLM，未来涉及历史 LLM 策略时需另做预训练未来知识隔离与前向记录。
